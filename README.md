# 🦷 Tony Dental Clinic


A modern, clean, and responsive dental clinic website built using **HTML, CSS, and JavaScript**.

This project is created as a frontend web development portfolio project to demonstrate responsive design, multi-page website structure, reusable UI components, navigation, service sections, team sections, and an appointment contact form.

---

## 🌐 Project Overview

**Tony Dental Clinic** is a fictional dental clinic website designed with a professional and user-friendly interface.

The website focuses on:

* Clean and modern UI
* Responsive design
* Easy navigation
* Dental service presentation
* Clinic information
* Dental team section
* Appointment/contact form
* Mobile-friendly layout

## 🎨 Design System

The project follows a simple and professional design system.

### Color Palette

| Color         | HEX       | Usage                                 |
| ------------- | --------- | ------------------------------------- |
| Primary       | `#2563EB` | Buttons, links and important elements |
| Primary Hover | `#1D4ED8` | Hover states                          |
| Secondary     | `#0F172A` | Headings and dark sections            |
| Background    | `#F8FAFC` | Main background                       |
| White         | `#FFFFFF` | Cards and navbar                      |
| Text          | `#334155` | Body text                             |
| Light Text    | `#64748B` | Secondary text                        |
| Border        | `#E2E8F0` | Borders                               |
| Success       | `#16A34A` | Success messages                      |
| Error         | `#DC2626` | Error messages                        |

The complete design system is documented in [`style.md`](style.md).

## 📱 Responsive Design

The website is designed for:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop

### Breakpoints

```text
Mobile  → < 768px
Tablet  → 768px – 1023px
Desktop → ≥ 1024px
```

The layout adapts to different screen sizes using responsive CSS techniques.

## 🚀 Getting Started

No build tools or frameworks are required.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/tony-dental-clinic.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the website

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
